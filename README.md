# Angular + Spring Boot

Monorepo z dwoma projektami:

- `frontend` - aplikacja Angular
- `backend/demo` - aplikacja Spring Boot

## Uruchamianie

Frontend:

```bash
cd frontend
npm install
npm start
```

Backend na Windows:

```powershell
cd backend/demo
.\mvnw.cmd spring-boot:run
```

Backend na macOS / Linux:

```bash
cd backend/demo
./mvnw spring-boot:run
```
